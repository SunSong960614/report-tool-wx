# 学校测评报告合成工具

用于将两份或以上、不同年龄段的 `.docx` 测评分析报告合成为一份学校测评分析报告。

## 使用方法

1. 双击 `start.bat`。
2. 浏览器打开 `http://127.0.0.1:18966`。
3. 上传不同年龄段报告，检查或修正识别出的年龄段。
4. 填写学校名称和报告年度，点击“生成学校报告”。
5. 浏览器会自动下载生成的 Word 报告。

本机版不会将文件上传到外部网络。线上版仅在当前请求中处理上传内容，解析完成后不保存源文件；生成报告使用临时目录，下载响应结束前即自动清理。

## 容器部署

应用支持通过 `Dockerfile` 部署，健康检查地址为 `/api/health`。运行时可配置：

- `PORT`：服务端口，默认 `18966`
- `HOST`：监听地址，本地默认 `127.0.0.1`，容器中设为 `0.0.0.0`
- `MAX_CONCURRENT_REQUESTS`：同时处理的请求数，默认 `2`
- `REPORT_FONT_REGULAR`、`REPORT_FONT_BOLD`：可选的中文字体文件路径

## Vercel 部署

Vercel 使用根目录的 `app.py` 作为 Flask 入口，静态文件位于 `public/`。受 Vercel Function 请求体限制，线上版单次上传文件合计不得超过 4MB。
